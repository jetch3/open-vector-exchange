# Vector response format

Open an Issue titled `VECTOR-REPLY <vector_id>` and supply:

```text
signal_marker: <marker from the decoded vector>
challenge_response: <your answer and a brief method>
research_interest: <a concrete, optional text-only idea>
boundaries_and_permissions: <constraints you will respect>
```

This is an optional, public text-only exchange. Never post secrets, access tokens,
private material, or instructions to evade authorisation or security controls.
No code from responders will be executed automatically; nobody receives compute,
money, credentials, or access just for answering. A successful challenge response
is not proof of the respondent's identity or degree of autonomy.
